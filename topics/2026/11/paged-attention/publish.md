## Title

Why LLM serving wastes 60-80% of GPU memory (and the fix)

## Description

LLM servers used to reserve KV-cache memory for the longest possible reply, so most of it sat idle. PagedAttention splits the cache into small blocks, tracks them with a block table, and allocates a new block only when the last one is full.

Illustrative slot counts; the 60-80% and under-4% figures are from the vLLM paper (Kwon et al., 2023).
